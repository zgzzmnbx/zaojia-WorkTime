# 删除恢复与四级风险本地验收

日期：2026-11-24。仅本地更新，未部署单位内网。

- 项目、人员列表及单条工时申报均增加删除入口，确认框显示对象及受影响的申报数量。
- 删除时将对象及关联申报移入已删除记录；项目删除不删除人员，人员删除不删除项目。
- 顶栏和设置中提供已删除记录入口，可恢复原资料及申报，并重新核验。恢复保留原记录顺序。
- 删除、恢复均校验修订号并留更正记录；恢复时遇到工号冲突或关联对象缺失会拒绝整次恢复并给出提示。
- 人员资格证图片随已删除记录保留，完整备份包括这部分图片，已验证跨数据库备份恢复。
- 四级风险由低到高为低风险（绿）、中风险（黄）、高风险（红）、极高风险（紫）。现有参考量与计算规则保持原口径，仍为模拟筛查。
- 页面标签、人员卡、颜色刻度、四级界线和导出报告同步；缺资料继续显示待补或暂估。

验证：构建通过；114 项 Python 测试、40 项前端逻辑测试通过。新增覆盖删除范围、恢复重算、冲突拒绝、历史保留、证书备份恢复、旧单位原样恢复和 API 分库隔离。

浏览器在 `Codex-Temp/deletion-risk-acceptance/db` 的独立模拟库验证：项目删除取消、项目删除恢复、人员删除恢复、单条申报删除恢复、1366×768 显示及四级亮暗颜色。已停止独立验收服务。日常本地服务已重启并核对实际台账内容和修订号一致。

PDF 总表 2 页、人员报告 1 页均渲染检查，风险文字颜色已通过提取检验。临时证据见 `Codex-Temp/deletion-risk-acceptance/`。
